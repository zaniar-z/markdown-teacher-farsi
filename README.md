# markdown-teacher-farsi

آموزش کامل و جامع مارک‌داون به فارسی + معرفی Obsidian.

## فایل‌ها

- `markdown-teacher.html` — صفحه آموزشی تک‌فایله (HTML/CSS/JS خالص)

## چه چیزی یاد می‌گیرید

- مبانی Markdown: سربرگ، متن، لیست، لینک، تصویر، کد، جدول
- تکنیک‌های پیشرفته: نقل قول، HTML خام، فرانت‌متر، بهترین تمرین‌ها
- معرفی Obsidian و اتصال آن به ایجنت‌های AI

## اجرا

فایل را مستقیم در مرورگر باز کنید:

```
markdown-teacher.html
```

نیازی به نصب یا build نیست.

## امکانات صفحه

- تم تیره/روشن (کلید `Ctrl+Shift+L`)
- تب‌های دسته‌بندی: همه / مقدماتی / پیشرفته / آبسیدین
- دکمه کپی برای بلوک‌های کد
- پس‌زمینه تعاملی p5.js
